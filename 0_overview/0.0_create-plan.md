# 計画：参加記録CSVの匿名化集計およびグラフ化機能（plan.md）

## 技術スタック
- 言語 / フレームワーク: Excel VBA（Microsoft Excel 2016以降 / Windows環境想定）
- データベース / ストレージ: なし（処理用一時シート上で完結し、処理後に破棄）
- 主要ライブラリ / 参照オブジェクト:
  - `ADODB.Stream`（UTF-8文字コードの正確な読み込みのため、遅延バインディング `CreateObject("ADODB.Stream")` で使用）
  - `Scripting.Dictionary`（ニックネームごとの参加回数集計のため、遅延バインディングで使用）
  - Excel標準 `ChartObject`（集計結果からのグラフ生成および `.Export` メソッドによるPNG画像出力）

## アーキテクチャ方針
- モジュール構成（単一標準モジュール内での責務分離）:
  1. `Main_ExportParticipationGraph`: エントリーポイント（ファイル選択ダイアログ、全体の進行制御、完了・エラー通知）
  2. `LoadAndValidateCsv`: UTF-8読み込み、改行コード（CRLF）・カンマ区切り・必須ヘッダ（`実施日`, `場所`, `参加者氏名`, `ニックネーム`）の検証
  3. `AggregateWithoutRealName`: 「参加者氏名」列を除外した状態でのニックネーム別カウント集計と昇順ソート
  4. `CreateAndExportChart`: 集計結果の一時シート出力、棒グラフ生成、PNGファイル書き出し、一時データの完全消去
- エラーハンドリング・バリデーション方針:
  - ファイル選択キャンセル時はエラーとせず静かに終了する。
  - 改行コードに `vbCrLf`（CRLF）が含まれない場合、カンマ区切りでない場合、またはヘッダに「実施日」「場所」「参加者氏名」「ニックネーム」のいずれかが欠けている場合はバリデーションエラーとして処理を中断し、`MsgBox` で具体的な理由を通知する（AC-4対応）。
  - 処理中に予期せぬエラーが発生した場合も `On Error GoTo` で捕捉し、一時シートやメモリ上の「参加者氏名」データが残らないよう必ずクリーンアップ処理を実行する（AC-5対応）。

## 主要な設計判断（なぜそれを選んだか）
- **Excel VBAの採用**：事務担当者が追加の環境構築（Python等）なしで、手元のExcelからボタン1つで即座に実行・画像確認できるようにするため。
- **`ADODB.Stream` の採用（遅延バインディング）**：CSVの文字コードがUTF-8であるため、VBA標準の `Line Input` による文字化けを防ぎ、かつVBEでの参照設定の手間を省くため。
- **`Scripting.Dictionary` + バブル/クイックソートによる集計**：ピボットテーブルを使わずメモリ上で「参加者氏名」を除外したまま集計・昇順ソートすることで、ワークシート上に個人情報が一切書き込まれない設計（プライバシー保護）を担保するため（AC-1, AC-5対応）。

## データモデル / 入出力仕様
- **入力CSV仕様**:
  - 文字コード: UTF-8（BOMあり・なし両対応）
  - 改行コード: CRLF（`vbCrLf`）
  - 区切り文字: カンマ（`,`）
  - 必須ヘッダ列: `実施日`, `場所`, `参加者氏名`, `ニックネーム`（順不同可、存在チェック必須）
- **内部集計データ構造**:
  - Key: `ニックネーム`（文字列、空白は除外または `(未設定)` 扱い）
  - Value: `参加回数`（長整数型 `Long`、参加者数の昇順でソート）
- **出力画像仕様**:
  - 出力先: 入力CSVと同じフォルダ内
  - ファイル名: `参加集計グラフ_YYYYMMDD_HHMMSS.png`
  - グラフ種類: 集合横棒グラフ（または縦棒グラフ）、データ系列は「参加者数（昇順）」
